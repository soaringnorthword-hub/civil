挡墙施工台账  报检照片登记助手  v1.1.0

============================================================
一、这是什么
============================================================
把每天收到的照片（现场手持「影像资料采集标识牌」、报检单翻拍、微信群消息截图）
自动识别出「里程、部位/第N模、设计顶宽底宽、方量、日期」等字段，
自动定位到《一工区施工台账（挡墙）》里对应的挡墙块和部位行，一键写入。

============================================================
二、两种识别引擎（v1.1 新增，务必先选对）
============================================================
点右下【设置】可以切换。这是本版本最关键的变化。

【本地离线 OCR】
  适合：微信群里的**文字消息截图**、**电脑打印的报检单**。
  实测：印刷体字段置信度 0.99 以上，准确。
  缺点：**手写体基本读不出来**。实测两张真实的现场标识牌（全手写），
        印刷表头全对，手写部分全错——"1.96" 读成 "96"、"1.5" 读成 "5"、
        里程 "K28+152.719" 读成 "K8+152"，姓名日期全丢。
        放大图片、锐化、增强对比度都试过，**没有任何改善**。
  优点：免密钥、不联网、免费。

【视觉大模型】（推荐，用于现场标识牌）
  适合：全部**手写**的「MM项目影像资料采集标识牌」。
  需要：联网 + 一个 API Key（通义千问/智谱/硅基流动/OpenAI 任选）。
  费用：每张约几分钱。
  配置：设置 → 选「视觉大模型」→ 选服务商 → 填 API Key → 点【测试连接】→ 保存。
        通义千问的 Key 在 dashscope.aliyuncs.com 免费申请，有免费额度。
  Key 只保存在本机（%APPDATA%\TzLedger\config.json），不上传任何第三方。

如果没配 Key 就选了「视觉大模型」，程序会自动回退本地 OCR 并提示。

============================================================
三、三步使用
============================================================
第 1 步  选台账
    点左上【选择台账】，选中你的《一工区施工台账（挡墙）20xx.xx.xx.xlsx》。
    窗口右上角会显示"已载入 xxx 个挡墙块"。

第 2 步  加照片、识别
    【添加照片】或【添加文件夹】，可多选。点【① 开始识别】。

    结果表各列说明：
      #        序号
      照片     文件名
      单据     程序判断的类型：模板报验 / 浇筑
      里程     识别到的里程起止
      部位     第几层墙身 / 基础
      本次高   本次浇筑（或报验）高度
      方量     设计方量（模板牌没有，程序用设计尺寸反算）
      强度     混凝土等级
      日期     施工/报验日期
      台账块   匹配到的挡墙块行范围
      目标行   具体要写入的那一行
      状态     见下

    状态说明：
      ✔ 就绪          正常，可直接写入
      ⚠ 需确认        能写入，但有需要你看一眼的地方
      ✗ 已拒绝（红底）识别结果明显错误，**程序拒绝写入**，需人工修正
      ✗ 未定位        里程没对上台账里的块，需人工指定
      ✗ 失败          识别过程报错

第 3 步  核对、写入
    • 双击任意一行 → 打开编辑框，可手工改里程/部位/尺寸/日期，改完自动重新定位。
    • 【查看OCR原文】→ 看到程序从图里读到的原始文字，便于判断错在哪。
    • 状态是「未定位」但里程没错 → 选中该行点【指定台账块】，
      会列出该里程对应的所有块（含长度、左右侧、结构形式、已填/预留层数），
      由你选定一个。
    • 确认后点【② 写入台账】。写入前自动备份原文件（同目录 .bak）。
    • 【③ 导出结果】可导出当期登记清单 Excel，便于交监理或存档。
    • 勾选【允许覆盖已填行】后才会覆盖台账里已有数据的行；默认跳过不覆盖。

============================================================
四、安全校验（v1.1 新增，防止把错数据写进台账）
============================================================
程序在写入前做硬校验，任何一条触发都会被拒绝（红色，不写入）：
  1. 里程跨度 > 500 m —— 单个挡墙块只有 4~12 m，跨 500 m 必然是识别错。
     实测老版本会把 "K28+152" 错读成 "K8+152"，再"部分重叠"匹配到 K24 段，
     一按写入就把 K28 的数据写进 K24 的墙身行，外表完全看不出来。现已被拦死。
  2. 顶宽/底宽不在 0.2~8 m —— 手写小数点丢失（1.96→196）会触发。
  3. 高度不在 0.05~8 m、方量不在 0.1~500 m³。
  4. 顶宽明显大于底宽 —— 疑似顶底宽认反。
  5. 只能"完全包含"才自动定位；跨多块、部分重叠、里程对不上，一律不自动选，
     必须人工【指定台账块】。台账里存在并行重复段（同一里程两套块），
     这种情况也会列出来让你选，绝不自己猜。

============================================================
五、模板报验牌怎么进台账
============================================================
现场标识牌是「模板报验」，牌上写的是设计/实测顶宽底宽和报验标高，
没有方量、没有强度、没有浇筑日期。程序按下面口径处理：
  O 顶宽 ← 牌上"设计顶宽"
  P 底宽 ← 牌上"设计底宽"
  Q 高、J 本次浇筑 ← 报验标高差（如"（0-1.5）m"就是 1.5）
  N 施工日期 ← 牌上日期
  T 浇筑日期 ← 留空（模板报验不是浇筑）
  S 设计方量 ← 按梯形断面反算：(顶宽+底宽)÷2 × 高 × 块长
  R 强度 ← 留空（牌上没有）
  部位 ← "第一模"当第 1 层墙身处理
  实测顶宽/底宽、检查结论、质检员、施工员 ← 台账没有对应列，只在提示里显示

注意：反算方量是预估值，与台账设计断面方量可能差 5~15%（实测一例：
反算 31.36、台账 32）。浇筑后请按浇筑报检单校正。

============================================================
六、公式列说明（重要）
============================================================
台账里 K/M/Q/U/V/W/X 大量是公式（=K212+J213、=J166、
=IF(S="","",ROUND(S*0.8,0)) 等）。程序**绝不覆盖公式**，
遇到公式格自动跳过并提示"已保留、由表格自动联动"。

代价是：程序写完后 U/V/W 显示 0（openpyxl 不重算公式）。
用 Excel/WPS 打开台账会自动算出来，或按一下 F9。

七、常见问题
============================================================
Q：现场标识牌识别不出来
A：手写必须用「视觉大模型」。本地 OCR 只能读印刷体，这是引擎能力边界，
   不是参数没调好。

Q：识别出来的里程/尺寸明显不对
A：状态会是「已拒绝」，程序不会写入。双击该行手工改，或直接看牌重填。

Q：提示"台账文件被占用，无法保存"
A：先在 Excel/WPS 里关闭该台账再写入。只关这个文件，不用退程序。

Q：写入后 U/V/W 列没数字
A：公式列。打开台账按 F9 或保存一次即可。

Q：能给别人用吗
A：可以。装安装包或整个 TzLedger 文件夹拷过去，对方电脑不用装 Python。
   如果用视觉大模型，对方需要自己填 API Key（或者共用同一个 Key）。

Q：照片会上传到哪里吗
A：本地 OCR 模式：不联网，照片不出本机。
   视觉大模型模式：照片会发送到你选定的服务商（如阿里云）做识别。
